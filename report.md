## Summary

This dissertation segment (Chapters 4 and 5) presents a two-tier software architecture and algorithmic framework—comprising the foundational `RS-DRL` and its cyber-physical extension `RS-DRL+`—designed to reconcile sub-millisecond real-time decision-making with formal runtime safety assurances in self-adaptive systems. In the first tier (`RS-DRL`), the framework decouples $\mathcal{O}(1)$ online Deep Q-Network (DQN) inference ($<0.5\text{ ms}$) from asynchronous statistical model checking (`UPPAAL-SMC`) and background gradient updates via lock-free double buffering, while utilizing optimistic Bernoulli reward shaping ($\rho$) on failed transitions to escape local optima in sparse-reward Quality-of-Service (QoS) spaces. In the second tier (`RS-DRL+`), the architecture addresses the hard real-time deadlines, severe failure imbalance ($>90\%$), and surrogate-to-physics reality gap of cyber-physical systems through two domain-agnostic patterns: Specification-Guided Offline Synthesis (`SG-OS`), which shapes offline replay logs using near-miss recoverability margins (`MU-RS-DRL`) and confidence buffers (`CM-RS-DRL`), and Contract-Anytime Elastic Plan-Phase Verification (`CA-EPV` / `PG-ALR`), which restricts online surrogate verification to a 1-hop neighborhood along the top-$m$ offline `TreeSHAP` sensitivity dimensions with provable bounds on computational complexity and reality-gap degradation. Extensive empirical evaluations across the `DeltaIoT` wireless sensor network benchmark (up to $4,096$ configurations) and $2,000$ closed-loop 6-DOF physical flight simulations in `DARTSim` demonstrate substantial improvements in physical survival, QoS compliance, and decision latency over state-of-the-art search-based, explanation-driven, and runtime shielding baselines.

## Strengths

* **Effective Temporal Decoupling and Lock-Free Concurrency Architecture:** The foundational `RS-DRL` design elegantly resolves the multi-second bottleneck of formal statistical verification by relocating `UPPAAL-SMC` out of the synchronous forward planning path into an asynchronous feedback loop coupled with lock-free double buffering (`AtomicSwap` and ring buffers). This enables deterministic sub-millisecond ($\mathcal{O}(1)$) policy inference while preserving formal QoS guidance and eliminating latency jitter during concurrent background training.
* **Principled Mitigation of the Reality Gap under Hard Real-Time Deadlines:** The proposed `CA-EPV` (`PG-ALR`) pattern provides a highly original three-stage contract-anytime hierarchy that bounds online surrogate verification to a linear $\mathcal{O}(m \cdot K)$ $L_1$ cross-polytope neighborhood along pre-extracted `TreeSHAP` dimensions (Proposition 4-10-1) and enforces a guarded fallback rule with formal worst-case physical safety and utility bounds under surrogate calibration error $\epsilon_{\max}$ (Proposition 4-10-2). Empirically, this prevents the erratic maneuvers and $11\%$ sim-to-real crash drop suffered by exhaustive runtime shields in 6-DOF UAV flight simulations while executing roughly $270\times$ faster ($<3.5\text{ ms}$ vs. $129.95\text{ ms}$).
* **Domain-Independent Specification-Guided Reward Reshaping and Architectural Subsumption:** By combining failure breadth and deficit depth in `MU-RS-DRL` with boundary confidence cushions in `CM-RS-DRL`, the `SG-OS` pattern effectively overcomes both the "safety through inaction" trap and gradient divergence in failure-dominated logs ($90.98\%$ failures in `DARTSim`) as well as massive $4,096$-action spaces (`DeltaIoTv2`). Furthermore, the architecture demonstrates graceful cross-domain subsumption, automatically defaulting to the $<0.25\text{ ms}$ fast path in over $96\%$ of soft-QoS `DeltaIoT` cycles while achieving $8.32\%$ packet loss over $250,000\times$ faster than symbolic model checking (`PRISM`).

## Weaknesses

* **Lack of Comparisons Against Dedicated Offline RL and Constrained RL Baselines, and Coupling of $d=1$ Truncation with Reward Shaping:** In Tier 1 (`SG-OS`), the policy is synthesized purely offline from static operational logs with $90.98\%$ failures by setting the terminal flag $d=1$ (Equation 4-5) to eliminate Bellman bootstrapping—reducing multi-step TD learning to a myopic contextual bandit—combined with heuristic multi-constraint reward shaping (`MU-RS-DRL` / `CM-RS-DRL`). Because standard off-policy DQN is known to diverge offline due to out-of-distribution action extrapolation, the authors might consider decoupling the effect of $d=1$ truncation from reward shaping via an explicit contextual-bandit baseline ($\rho=0, d=1$) and benchmarking against established offline value-regularization methods and primal-dual Constrained MDP algorithms that adapt constraint penalties without manual hyperparameter tuning (Reference Paper: Conservative Q-Learning for Offline Reinforcement Learning, Aviral Kumar et al., 2020; Reference Paper: Reward Constrained Policy Optimization, Chen Tessler et al., 2019).
* **Methodological Discrepancy Between `TreeSHAP` and Polynomial Surrogate Models, and Action-Space Dimensionality in `DARTSim`:** Section 4-10-1 (Footnote 6) justifies `TreeSHAP` by leveraging the tree structure of the surrogate models for $\mathcal{O}(T \cdot L \cdot D^2)$ complexity, whereas Section 5-7-2 states that the 12 `DARTSim` surrogates are actually polynomial regressions; additionally, the authors should clarify how a static, globally averaged offline feature ranking remains sound when local state-dependent interactions cause a pruned feature ($j \notin \text{Top-}m$) to drive a runtime violation. Furthermore, Section 4-10-2 and Figure 5-6 define the `DARTSim` discrete action space as having $d_A = 3$ variables ($2 \times 2 \times 15 = 60$ options), whereas Table 5-13 ranks $6$ controllable variables (including `DeltaIoT`'s `Transmit Power`) and Table 5-14 reports $3.8 \pm 0.4$ candidates for $m=2$ binary features (which mathematically allow at most $3$ candidates in a 1-hop $L_1$ neighborhood), warranting clarification of the surrogate/explainer classes and action discretization.
* **Internal Inconsistencies Across Algorithms, Equations, Figures, and Statistical Tables:** Several presentation and technical discrepancies across Chapters 4 and 5 should be harmonized to strengthen reproducibility: (1) a PCTL operator mismatch in Section 4-7 where an invariance property is written with the reachability quantifier $\Diamond_{\le T}$ instead of $\Box_{\le T}$; (2) sequential blocking pseudocode in Algorithm 4-1 vs. the concurrent lock-free architecture, and ambiguity in Algorithm 4-2 regarding whether `MU-RS-DRL` and `CM-RS-DRL` are mutually exclusive modes; (3) conflicting target network update rules (Polyak soft updates with overloaded symbol $\tau$ in Chapter 4 vs. periodic hard updates every $C$ steps in Table 5-4); (4) mismatched limit conditions in the Architectural Subsumption equations ($T_{\text{budget}} \to \infty$ in Eq. 4-1 vs. $\mathcal{E}(of) \le \epsilon_{\text{threshold}}$ in Eq. 5-3); and (5) numerical/plotting inconsistencies in Chapter 5, including identical reward curves across all three physical QoS panels of Figure 5-3, static $v_1$ benchmark scores plotted inside the $v_3$ comparison of Figure 5-7, mismatched `Raw DQN` trajectories in Figure 5-11 vs. the prose, `DARTSim` latencies plotted on the `DeltaIoT` bars of Figure 5-17, and conflation of the exact binomial McNemar formula with Fisher's exact test in Equation 5-7 alongside contingency mismatches in Table 5-15.

1. **Temporal Logic Operator Mismatch in the Packet Loss Specification Example (Section 4-7, Page 16):**
   * **Definitive Flaw:** In Section 4-7 (page 15), Equation (4-3) formulates the general domain-independent safety/invariance specification in Probabilistic Computation Tree Logic (PCTL) using the "always" (invariance) path operator:
     $$\psi = P_{\ge 1-\alpha} [\Box_{\le T} (C_j(s) \le \tau_j)]$$
     which requires that the quality metric $C_j(s)$ remains within the permissible threshold $\tau_j$ throughout the entire time horizon $T$. Immediately following Equation (4-3) at the top of page 16 (lines 3–5), the text illustrates this invariance property for the wireless sensor network benchmark—explicitly described in prose as the packet loss rate *never exceeding* the permissible threshold ("عدم تجاوز نرخ اتلاف بسته‌ها از آستانه مجاز")—using the formula:
     $$\psi = P_{\ge 0.99} [\Diamond_{\le T} (\text{PacketLoss} < 0.1)]$$

4. **Shared Memory Access Semantics and Lock-Free Double-Buffering Mechanics (Sections 4-4-1 and 4-6, Pages 10 and 14–15):**
   * **Potential Concern:** Two concurrency details in the lock-free shared knowledge architecture warrant clarification to ensure thread-safety and systems-level reproducibility:
     1. *SPSC Ring Buffer vs. Random-Access Replay Buffer:* Section 4-4-1 (page 10, item 2 and Footnote 4) states that transitions in the experience replay buffer $\mathcal{D}$ are organized via a Single-Producer Single-Consumer (`SPSC`) lock-free ring buffer where the feedback thread appends transitions and the training thread consumes them. However, a standard FIFO SPSC queue pops/consumes elements sequentially, whereas Deep Q-Learning (Figure 4-3, Algorithm 4-1 line 11, and Figure 4-5 Store 4: `[Thread-Safe Append-Only · Batch Sample]`) requires uniform random minibatch sampling ($B \sim \mathcal{D}$) over a persistent historical buffer of $10^5$ transitions (while Store 2 in Figure 4-5, the `Real-Time Telemetry Ring Buffer`, is labeled `[Lock-Free Single-Producer Multiple-Consumer]`). Furthermore, Table 4-3 (page 15, last row) lists the Learner (`Train`) as having *both* read and write access to $\mathcal{D}$ ("دسترسی نوشتن: بافر $\mathcal{D}$ و وزن‌های جدید $\theta$"), which contradicts Figure 4-5 where only the Formal Verifier writes to Store 4 ($\mathcal{D}$) and reward shaping is performed on the sampled minibatch $B$ in local memory (Figure 4-3 and Algorithm 4-1, lines 11–18).
     2. *Pointer Swap vs. Shadow Copy in Lock-Free Double Buffering:* Section 4-4-1 (page 10, item 1) and Figure 4-3 describe lock-free weight synchronization between $\theta_{\text{active}}$ and $\theta_{\text{train}}$ via an $\mathcal{O}(1)$ bidirectional pointer exchange `AtomicSwap(\theta_{\text{active}}, \theta_{\text{train}})` with zero reader locks (whereas Figure 4-2 on page 5 writes a unidirectional assignment $\theta_{\text{active}} \leftarrow \theta_{\text{train}}$ and Figure 4-1/page 14 overload $\theta, \theta'$). In a two-buffer pointer swap without reader locks, if the pointers are simply exchanged after a gradient step and the training thread immediately begins mutating the newly swapped $\theta_{\text{train}}$ buffer (which was just $\theta_{\text{active}}$), two hazards arise: (a) an in-flight inference pass on Path 1 that loaded the old $\theta_{\text{active}}$ pointer microseconds before the swap could experience concurrent memory mutation (torn reads) while completing its forward pass, and (b) the old $\theta_{\text{active}}$ buffer holds stale weights from before the latest gradient update unless the updated weights are copied to the shadow buffer before the next gradient step.
   * **Suggested Fix:** In Section 4-4-1 and Section 4-6, clarify that $\mathcal{D}$ is a circular array with atomic write-index advancement supporting lock-free concurrent random-access reads for minibatch sampling (or that an SPSC queue feeds into $\mathcal{D}$), and remove "بافر $\mathcal{D}$" from the `Train` component's write-access column in Table 4-3. 1. **Inconsistent Constraint Satisfaction Condition for Heterogeneous Thresholds $\tau_k$ Across Text, Figures, and Algorithm 4-2:**

# HIGH LEVEL SUMMARY

## Summary

This doctoral dissertation presents a two-tier Deep Reinforcement Learning (DRL) architectural framework—comprising foundational Randomized Reward-Shaped DRL (`RS-DRL`) and its real-time cyber-physical extension (`RS-DRL+`)—to manage runtime uncertainty in self-adaptive systems (SAS) operating under the MAPE-K feedback loop. In the first tier, `RS-DRL` addresses local optima stagnation in large discrete adaptation spaces (up to 4,096 options) by injecting Bernoulli-controlled optimistic rewards into failed transitions within the experience replay buffer while decoupling statistical model checking (`UPPAAL-SMC`) into a non-blocking, lock-free asynchronous feedback thread. In the second tier, to resolve the "real-time planning trilemma" in safety-critical cyber-physical systems (CPS), `RS-DRL+` introduces two domain-agnostic software design patterns: (1) Specification-Guided Offline Synthesis (`SG-OS`, instantiated via `MU-RS-DRL` and `CM-RS-DRL`), which uses multi-constraint recoverability margins, confidence buffering, and action utility incentives under a contextual-bandit formulation to learn stable policies from offline logs dominated by over 90% failure transitions; and (2) Contract-Anytime Elastic Plan-Phase Verification (`CA-EPV` / `PG-ALR`), which anchors runtime adaptation on sub-millisecond neural inference and restricts defensive surrogate verification to a 1-hop neighborhood along offline-extracted top-$m$ `TreeSHAP` sensitivity dimensions, backed by formal complexity ($\mathcal{O}(m \cdot K)$) and reality-gap bounds.

## Strengths

* **Asynchronous Formal Verification and Goal-Agnostic Exploration in Large Adaptation Spaces:** The foundational `RS-DRL` architecture creatively decouples $\mathcal{O}(1)$ neural policy inference ($< 0.5\text{ ms}$) from multi-second `UPPAAL-SMC` statistical model checking via a lock-free double-buffered architecture, while using Bernoulli-controlled optimistic reward injection in the replay buffer to escape local optima in threshold-based QoS regimes where goal-coordinate relabeling methods fail.
* **Resilient Offline Policy Synthesis Under Extreme Failure Imbalance (`SG-OS`):** The `SG-OS` pattern (`MU-RS-DRL` and `CM-RS-DRL`) introduces a principled mathematical decomposition of failure breadth and depth via the recoverability margin $\mathcal{M}(s,a)$, paired with action utility incentives $\mathcal{U}_{\text{inc}}(a)$, confidence buffering $\bar{\mathcal{B}}(s,a)$, and a single-step contextual-bandit formulation ($d=1$) that prevents both catastrophic Q-value collapse and passive "safety-through-inaction" behavior when training on operational logs containing over 90% constraint violations.
* **Bounded Real-Time Verification and Reality-Gap Mitigation (`CA-EPV` / `PG-ALR`):** By anchoring runtime planning on a compiled DRL policy and restricting fallback surrogate verification to a 1-hop cross-polytope neighborhood over top-$m$ `TreeSHAP` sensitivity dimensions, the `CA-EPV` pattern formally bounds candidate evaluations to $|\mathcal{N}(a_0)| \le 2m + 1$ (Proposition 1) and guarantees monotonic surrogate compliance alongside bounded physical degradation under calibration error (Proposition 2), achieving sub-$3.5\text{ ms}$ worst-case execution and outperforming full runtime shielding in 6-DOF closed-loop flights.
* **Comprehensive Cross-Domain Empirical and Statistical Validation:** The dissertation thoroughly validates both architectural tiers across two distinct exemplars—the `DeltaIoT` wireless sensor network (scaling from 216 to 4,096 discrete configurations) and the `DARTSim` UAV simulator (2,000 closed-loop 6-DOF physical flights across 200 scenarios and three corridor tolerance regimes)—supported by ablations, memory/latency profiling, and non-parametric statistical testing (Wilcoxon signed-rank, McNemar's test, Vargha–Delaney $\hat{A}_{12}$, Cohen's $d$, and Holm–Bonferroni corrections).

### [Theoretical Foundations, Benchmark System Modeling (DeltaIoT & DARTSim), & Complexity Analysis (Ch. 2)] (Pages: 44-67)

#### Potential Mistakes and Improvements

1. **Direction and Formal Construction of the NP-Hardness Reduction in Theorem 1 (Section 2-6-1, pp. 58–59 / Thesis pp. 31–32):**
   * **Definitive Flaw in Reduction Direction:** In Theorem 1 (p. 59 / Thesis p. 32), the proof of NP-hardness for the constrained network adaptation optimization problem states: *"برای اثبات، این مسئله را به مسئله کوله‌پشتی چندبعدی (MDKP) [۲۸] که ان‌پی-سخت بودن آن اثبات شده است، کاهش می‌دهیم"* ("To prove this, we reduce this problem to the Multi-Dimensional Knapsack Problem (MDKP)..."). In computational complexity theory, establishing that a target problem $Y$ (constrained network adaptation) is NP-hard requires a polynomial-time reduction in the opposite direction—reducing a known NP-hard problem $X$ *to* an instance of $Y$ ($X \le_p Y$)—to demonstrate that solving $Y$ is at least as hard as solving $X$. Reducing the target adaptation problem to MDKP ($\text{Adaptation} \le_p \text{MDKP}$) only demonstrates that a simplified version of the adaptation problem is no harder than MDKP and can be solved via an MDKP oracle.
   * **Potential Concern Regarding Proof Completeness:** Beyond the reversed direction of the reduction, the four numbered items on page 59 (Thesis p. 32) provide an informal structural analogy between problem variables rather than a formal polynomial-time transformation:
     * In `DeltaIoT`, each sensor node $v \in V$ must select *exactly one* local configuration $a_v \in A_v$ from its discrete set of power and routing options ($A = \prod_{v \in V} A_v$), which structurally corresponds to the **Multiple-Choice Multi-Dimensional Knapsack Problem (MMKP)** rather than standard 0-1 MDKP.
     * In MDKP/MMKP, item weights and profits combine additively across items, whereas in `DeltaIoT`, end-to-end path packet loss $P_{\text{loss}}(\mathcal{P}) = 1 - \prod_{i=1}^{k-1} \text{PDR}_{(v_i, v_{i+1})}(t)$ (Eq. 2-6) and multi-hop latency are nonlinear/multiplicative over paths, and the objective is *minimizing* energy subject to *upper-bound* QoS thresholds ($\text{PacketLoss}(a) < \theta_P$, $\text{Latency}(a) < \theta_L$).
   * **Suggested Improvement:** Reverse the stated direction of the reduction ($\text{MMKP} \le_p \text{Adaptation}$) and construct a concrete 1-hop star network topology connected to the gateway (eliminating multi-hop nonlinear path couplings) where each disjoint item class in an arbitrary MMKP instance maps to a sensor node $v \in V$, each item choice within that class maps to a local configuration $a_v \in A_v$ with energy cost $\text{Energy}(v, a_v)$, and channel parameters ($\text{PL}(e), \alpha, \beta$) are chosen so that satisfying the packet-loss and latency budgets $\theta_P, \theta_L$ while achieving total energy $\le E_{\text{target}}$ holds if and only if the MMKP instance admits a valid packing.
